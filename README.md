# STRACK
The Centralized HEI Student Activity Platform (`strack`) is a robust console-based application developed using Java JDBC and a relational MySQL database. It streamlines institutional data management through secure, role-based access control for students, teachers, and administrators.

Students can securely view their personal profiles, attendance percentages, and detailed half-yearly or annual exam grades. Teachers can manage their assigned class sections by updating student attendance, academic performance, disciplinary flags, and subject-specific marks. Meanwhile, administrators enjoy comprehensive CRUD capabilities to efficiently add, view, modify, and delete both student and staff records.
